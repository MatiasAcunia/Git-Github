# Python Fundamentals — UTEC

Ejercicios de Python 3.8 de la plataforma UTEC. Código a completar por el estudiante.

## Carpetas
- `hello_world/`: salida determinista, pip/pycodestyle y entornos virtuales.
- `control_flow/`: condicionales, bucles y formato de salida.

Todos los scripts deben comenzar con `#!/usr/bin/env python3`, ser ejecutables en Ubuntu, finalizar en newline y respetar PEP8 (pycodestyle 2.7.x). No instalar bibliotecas externas para resolver los ejercicios.

## Entrega
Subir el repositorio `Git-Github` a la plataforma seleccionando la carpeta/archivo correspondiente, según cómo lo acepte el formulario. Los enunciados especifican las rutas internas `python_fundamentals/...`.
