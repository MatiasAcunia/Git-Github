# Shell — I/O Redirections and Filters

Scripts para el proyecto de redirecciones de entrada/salida y filtros.

- `0-hello_world` — imprime `Hello, World`.
- `1-confused_smiley` — imprime el smiley solicitado.
- `2-hellofile` — muestra `/etc/passwd`.
- `3-twofiles` — muestra `/etc/passwd` y `/etc/hosts`.
- `4-lastlines` — muestra las últimas 10 líneas de `/etc/passwd`.
- `5-firstlines` — muestra las primeras 10 líneas de `/etc/passwd`.
- `6-third_line` — muestra la tercera línea de `iacta`.
- `7-file` — crea el archivo con el nombre especial pedido y escribe `Best School`.
- `8-cwd_state` — guarda `ls -la` en `ls_cwd_content`.
- `9-duplicate_last_line` — duplica la última línea de `iacta`.
- `10-no_more_js` — elimina archivos regulares `.js` recursivamente.
- `11-directories` — cuenta directorios y subdirectorios.
- `12-newest_files` — muestra las 10 entradas más recientes.
- `13-unique` — muestra líneas que aparecen exactamente una vez.
- `14-findthatword` — muestra líneas con `root` en `/etc/passwd`.
- `15-countthatword` — cuenta líneas con `bin` en `/etc/passwd`.
- `16-whatsnext` — muestra coincidencias con `root` y las 3 líneas siguientes.
- `17-hidethisword` — muestra líneas que no contienen `bin`.
- `18-letteronly` — muestra líneas de `sshd_config` que empiezan con una letra.
- `19-AZ` — transforma `A→Z` y `c→e`.
- `20-hiago` — elimina `c` y `C` de la entrada.
- `21-reverse` — invierte la entrada.
- `22-users_and_homes` — muestra usuarios y directorios home ordenados por usuario.
