# Shell, introducción - Basics
0-current_working_directory: Imprime la ruta absoluta del directorio de trabajo actual.
1-listit: Muestra el contenido del directorio actual.
2-bring_me_home: Cambia al directorio personal.
3-listfiles: Lista en formato largo.
4-listmorefiles: Lista en formato largo, incluyendo archivos ocultos.
5-listfilesdigitonly: Lista en formato largo con propietarios numéricos y archivos ocultos.
6-firstdirectory: Crea /tmp/my_first_directory.
7-movethatfile: Mueve /tmp/betty al nuevo directorio.
8-firstdelete: Elimina betty del nuevo directorio.
9-firstdirdeletion: Elimina /tmp/my_first_directory.
10-back: Vuelve al directorio de trabajo anterior.
11-lists: Lista el directorio actual, el padre y /boot, en ese orden.
12-file_type: Muestra el tipo de /tmp/iamafile.
13-symbolic_link: Crea __ls__ como enlace simbólico a /bin/ls.
14-copy_html: Copia archivos .html nuevos o más recientes al directorio padre.
15-lets_move: Mueve archivos con inicial mayúscula a /tmp/u.
16-clean_emacs: Elimina archivos del directorio actual terminados en ~.
17-tree: Crea welcome/to/school.
